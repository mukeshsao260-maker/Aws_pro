Bring your laptop, your questions and one idea you want to turn into a working prototype.

05 · FAQ

Quick answers.

Is this event free? +

Yes. This fictional event is presented as free for students.

Do I need prior AWS experience? +

No. The sessions are designed for beginners, while experienced students can extend the projects.

What should I bring? +

Bring a laptop, charger, college ID and an idea you would like to build.

Can I deploy this website? +

Yes. It is a static HTML, CSS and JavaScript project and can be deployed on GitHub Pages, Netlify or Vercel.
